# V1.0 验收手册

所有验收使用 `fixtures/` 中的虚构数据，真实报告需要获得合法处理权限后仅在自己的部署环境中测试。

| 场景 | 操作 | 预期 |
|---|---|---|
| 首次访问 | 打开本地首页 | 中文工作台，演示数据与模拟模式明确标识 |
| 文本 PDF | 上传 fixture PDF | 后台状态变更后出现页/行证据和候选值 |
| 扫描图片/PDF | 上传 fixture 扫描件 | 本地 OCR，显示 OCR 误识别风险 |
| Word | 上传 DOCX | 提取文本；明确物理页码和嵌入图像限制 |
| 非法格式 | 伪装扩展名/空文件 | 拒绝，不进入解析队列 |
| 过大上传 | 超过配置上限 | 明确报错，不无限占用内存 |
| 人工标注 | 选择原文行并录入字段 | 保存字段、证据关联和操作记录 |
| 模板 | 保存别名映射并应用 | 统一名称，不改写原始证据 |
| 数值规则 | 设置上下限和单位 | 超范围标记；单位不一致显示不确定 |
| 定性规则 | 配置明确正常/异常文本 | 仅匹配显式配置，未匹配不臆断 |
| 无阈值 | 去掉参考区间和匹配规则 | 不自动编造参考阈值 |
| 未同意 AI | 跳过预览/不勾选同意 | 前后端均阻止分析请求 |
| 模拟 AI | 选择证据，审核预览并同意 | 不访问模型网络，结果显示模拟及引用 |
| 真实 AI | 安全配置轮换后的密钥后测试 | 只能发送本次批准片段；用户另行验收 |
| 导出 | JSON/CSV/HTML | 值、状态、引用可复核；HTML 可本地打印 PDF |
| 历史 | 刷新/重启后查看 | SQLite 持久化保留报告、规则、模板 |
| 队列 | 同时上传多份 | 活跃 OCR 不超过并发限制；队列满明确拒绝 |
| 窄屏 | 小屏宽度打开 | 主要按钮、表单可访问，不重叠 |

## 医疗与数据安全人工验收

- 逐行比对小数点、负号、指数、单位和参考范围，特别是 OCR 字符 `0/O`、`1/l` 和 `μ/u`
- 规则来源应有机构审核；本应用不内置权威临床阈值库
- 合并单元格、参考人群条件、年龄/性别相关阈值不应被通用算法默认为适用
- 不把“正常范围”视为排除疾病，也不把异常值视为确定疾病
- 真实外发前逐行检查脱敏预览和专科/疾病背景；审核提供商合同和所在地合规要求
- 验收浏览器网络：模拟分析不应请求智谱；真实分析仅后端调用固定端点
- 切勿使用生产数据做公共演示、截图或压测

## 部署前必须另行完成

目标硬件压力测试、医院真实模板准确率评估、真实模型账户兼容性、容器构建、医院网络策略、备份恢复演练、多用户认证和安全合规。此项目不宣称这些事项已验收。
