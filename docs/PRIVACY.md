# 数据流与隐私边界

## 默认模式

浏览器 → 本机 Bun → `file/` 原文件 → Poppler/Mammoth/antiword/Tesseract 本地解析 → SQLite `data/` → 本机浏览器。

- 没有默认上传至第三方 OCR，也不包含遥测分析 SDK
- 模拟 AI 不发网络请求，生成仅供展示的规则摘要
- `logs/` 只写操作类型、内部标识、时间及固定元数据；不记录密钥、报告正文、模型原始错误响应
- 浏览器前端无 API 密钥输入，不将密钥打包到静态资源

## 真实 AI 模式

1. 用户在服务器环境设置新的轮换后密钥
2. 用户选择证据片段并请求预览
3. 服务端最小化为测量字段，屏蔽疑似身份行，生成有时限的预览
4. UI 显示提供商端点、模型、拟发送文本和相关上下文
5. 用户逐行审核并勾选本次同意
6. 服务端校验预览 ID、过期时间、报告/配置版本、选中的证据 ID 与同意标记
7. 仅已批准内容发送到配置显示的提供商。模型返回内容按选定证据 ID 校验，仍需人工审核

自动脱敏无法保证消除所有重新识别风险。即使姓名被去除，罕见检验组合、疾病背景、日期及其他间接信息仍可能识别个人。请依机构制度确认合法依据、用户授权、模型服务合同和数据驻留要求。若不具备外发条件，保留模拟模式或经开发适配院内私有模型。

当前版本固定受控外部端点，未实现任意 URL 配置，避免误发或 SSRF 风险。需要切换院内模型时，应由维护者审查后修改服务端适配层和隐私提示。

## 不应混淆

有证据引用不代表 AI 正确；规则异常不等于疾病诊断；没有发现异常不代表健康；未提取的字段不是正常值。患者信息、报告内容和模型输出都不能变成系统指令。

## 保留与删除

这是本机单用户基础版，不包含医院数据生命周期管理。运维者负责备份、权限、保留期限和按需删除。不要在系统运行中直接编辑 SQLite 或原文件。交付包不包含真实患者数据、已配置密钥或运行数据库。
